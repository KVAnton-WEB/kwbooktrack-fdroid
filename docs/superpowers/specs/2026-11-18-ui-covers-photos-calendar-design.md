# UI: обложки, фото заметок, календарь, просмотрщик фото

Дата: 2026-11-18. Статус: одобрено пользователем.

## Интент

Обложки и фото в списках/календаре обрезаются и искажаются (квадратные и
не-книжные коробки + Crop), фото заметки выглядит по-разному на трёх экранах,
в просмотрщике фото нет зума, обложки в календаре не кликабельны. Пользователь
хочет корректные пропорции без искажений, единый вид фото заметки, зум,
переход из календаря в деталь и сетку дней.

## Цели

1. Обложки в списке/сетке/деталях — коробка 2:3, минимальная обрезка, без искажений.
2. Фото заметки — единый тайл 120dp Fit (целиком, без обрезки) во всех местах.
3. Календарь — тайлы Fit, тонкая сетка границ дней, тап по обложке → деталь книги/фильма.
4. Просмотрщик фото — pinch-зум, double-tap 1↔2.5×, pan с клампингом, сброс при смене страницы.
5. Деталь фильма — обложка открывает просмотрщик (как в детали книги).

## Не-цели

- Выравнивание высот карточек сетки (1/2 строки заголовка).
- Новые зависимости (зум-библиотеки и т.п.).
- Перекройка layout календаря (7 колонок, ячейки 140dp остаются).
- Обложки в формах AddBook/MovieEdit и NoteDetail — уже 96×144 (2:3), не трогать.
- Экспорт/импорт, данные, навигационные маршруты.

## Анти-цели

- Искажение пропорций изображений; новая обрезка там, где её не было.
- Поломка существующей навигации и просмотра фото без зума.

## Ограничения

Jetpack Compose + Coil AsyncImage; штатные жесты foundation; house patterns
(ui/common для общих компонент, onOpenMedia-колбэки, PhotoGalleryDialog).
TDD для логики (математика зума), финальная визуальная проверка на устройстве
Nothing Phone A142 (1084×2412) со скриншотами до/после.

## Подходы (выбор)

- **Обложки**: (a) фикс-коробка 2:3 + Crop — выбрано: типичная обложка ≈2:3,
  обрезка минимальна, ряды ровные; (b) Fit — целиком, но леттербоксинг в
  списке/сетке; (c) динамический ratio по картинке — без обрезки, но рваная
  сетка и больше кода.
- **Фото заметок**: единый тайл Fit — выбрано (пользователь жалуется на
  обрезку); единый Crop отвергнут — обрезка остаётся.
- **Зум**: (a) свой модификатор на detectTransformGestures + graphicsLayer —
  выбрано (~50 строк, без зависимостей); (b) готовая zoomable-библиотека —
  новая зависимость ради одного экрана.

## Решения по файлам

1. **CoverImage** (`ui/common/CoverImage.kt:33-36`): `sizeDp` = высота,
   `modifier.height(sizeDp.dp).aspectRatio(2f/3f)` вместо `.size(sizeDp.dp)`;
   ContentScale.Crop остаётся. Вызывающие не меняются: LibraryScreen
   BookListCard:435 / MovieListCard:612 (64), BookDetailScreen:211 (96),
   MovieDetailScreen:157 (110). Сетка: LibraryScreen BookCoverCard:506-511 и
   MovieCoverCard:672-677 — `aspectRatio(3f/4f)` → `aspectRatio(2f/3f)`.
2. **Фото заметок**: общий компонент `NotePhotoTile` в ui/common — 120dp
   квадрат, rounded 8dp, фон surfaceVariant, ContentScale.Fit, onClick.
   Заменяет: NoteEditorScreen:262-274 (96dp Crop; кнопка удаления 28dp TopEnd
   остаётся поверх), NoteDetailScreen:353-366 (120dp Crop → Fit),
   BookDetailScreen NoteRow:565-574 и QuoteRow:611-620 (баннеры на всю
   ширину ×160/140dp → тайл 120dp).
3. **Календарь** (`ui/calendar/CalendarScreen.kt`): CoverTile:339 Crop → Fit;
   DayCell:242-329 — граница ячейки ~0.5dp outlineVariant (сетка дней);
   CoverTile — clickable → `onOpenMedia(MediaType, id)`; CalendarScreen
   принимает `onOpenMedia` (рядом с onBack:61-65), DayCell пробрасывает
   (isMovies уже есть:183). NavHost `KwBooktrackNavHost.kt:113-115` —
   колбэк по паттерну NoteDetail:139-147 → Routes.bookDetail(id) /
   Routes.movieDetail(id).
4. **Зум** (`ui/common/PhotoGalleryDialog.kt`): чистая математика зума
   (scale/offset, клампинг масштаба 1..4 и смещения по границам изображения)
   — отдельный класс/функции + юнит-тест; модификатор
   detectTransformGestures + detectTapGestures(onDoubleTap: 1↔2.5) +
   graphicsLayer; HorizontalPager `userScrollEnabled = scale == 1f`;
   сброс зума при смене страницы (LaunchedEffect(currentPage)).
5. **Деталь фильма** (`ui/movies/MovieDetailScreen.kt:155-159`): onClick
   обложки + PhotoGalleryDialog зеркально BookDetailScreen:180-189.
