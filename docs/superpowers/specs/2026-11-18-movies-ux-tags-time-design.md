# Фильмы: отметка просмотра, теги, поиск и время в статистике

Дата: 2026-11-18. Статус: утверждено (решение принято агентом по запросу
пользователя, без отдельного раунда вопросов).

## Интент пользователя (дословно)

1. «отмечать фильм просмотренным и добавлять дату просмотра нужно на главной
   вкладке фильма, без необходимости редактирования».
2. «возможность редактировать теги/ключевые слова, с поиском подстановок, как
   уже есть в некоторых полях (например переплет у книг) и добавить в основную
   строку поиска поддержку этих тегов».
3. «строку поиска сделать в одну строку, надпись "поиск по" можно убрать,
   просто оставить название/актер/режисер/тег и так понятно что это поиск».
4. «В статистике "минут просмотра" в верхней плашке заменить просто на
   "Время: " т.к. там часы и минуты и убери пробелы между числом и подписью
   40ч 45мин (а не 40 ч 45 мин)».
5. «В графиках тоже замени на время и переведи подписи из чистых минут в
   формат ч.мин например 4.45 так будет и компактно и понятно».
6. «при оценке звездочками, нужен больший контраст цвета между выбранными
   звездами и не выбранными, не выбранные может сделать не в зеленой гамме, а
   серой?»

## Цели

1. Карточка фильма: кнопка отметки просмотра с выбором даты (по умолчанию
   сегодня) — без входа в редактор. Повторный просмотр добавляет ещё одну дату.
2. Теги редактируются на карточке книги и фильма: чипы с удалением по тапу,
   поле добавления с подсказками из уже существующих тегов (тот же паттерн, что
   `SuggestionTextField` у переплёта).
3. Поиск библиотеки находит записи по тегам: частичное совпадение, без учёта
   регистра (в т.ч. кириллица), несколько слов — И.
4. Подсказка строки поиска без «Поиск по»: «Название, автор, ISBN, тег» /
   «Название, режиссёр, актёр, тег».
5. Плашка статистики фильмов: «Время: 40ч 45мин»; формат длительности во всём
   приложении — без пробелов между числом и единицей.
6. График времени: заголовок «Время по месяцам / по годам», подписи столбцов —
   часы.минуты: 285 мин → «4.45».
7. Звёзды рейтинга: выбранные — акцент (tertiary), пустые — серый
   `outlineVariant` вместо `onSurfaceVariant` (заметно темнее в тёмной теме,
   нейтрально-серый в светлой).

## Не-цели (YAGNI)

- Переименование тегов, удаление тега из таблицы `tags` (сироты остаются —
  см. «Риски»), массовое редактирование.
- Теги в редакторах книги/фильма (правка — на карточке).
- Снятие отметки «просмотрено» / удаление конкретной даты с карточки
  (это по-прежнему делает редактор).
- Изменение схемы БД и миграции: новых колонок и таблиц нет.
- Пагинация/оптимизация: фильтрация по тегам идёт в памяти по уже
  загруженному списку библиотеки.
- Изменение цвета залитых звёзд и отображения рейтинга в списке.

## Решения

| Вопрос | Решение | Почему |
| --- | --- | --- |
| Где искать по тегам | В `LibraryViewModel`: SQL-поиск даёт id текстовых совпадений, теги — в Kotlin | SQLite не складывает регистр кириллицы (`lower()`/`LIKE` работают только для ASCII); колонка `tags.name_search` потребовала бы миграции и бэкфилла, который тем же `lower()` не сделать |
| Поток тегов для поиска | новый `TagDao.observeTagsForAllMedia(): Flow<List<MediaTagName>>` | запрос уже есть в suspend-виде (`tagsForAllMedia`) для снимков; Room инвалидирует и `tags`, и `media_tags` — добавление тега сразу меняет выдачу |
| Формат даты просмотра на карточке | `DatePickerDialog` с сегодняшней датой по умолчанию | тот же Material3-календарь, что в `DatePickerField`; одна кнопка покрывает и «отметить», и «добавить дату» |
| Основная дата после добавления | минимальная из всех, остальные — в `media_dates` | инвариант `mediaDates()`: основная — самая ранняя; статистика и фильтры уже на него опираются |
| Атомарность добавления даты | `database.withTransaction`, как в `BookDetailViewModel.markFinished` | иначе падение между `movies.update` и `media_dates` оставит дату без основной |
| Формат подписи графика | чистая функция `formatDurationDot(285) = "4.45"` рядом с `splitDuration` | тестируется без Compose |
| Пробелы в длительности | правка строк `duration_*`: `%1$dч %2$dмин` | одна точка правки на всё приложение (список, карточка, статистика) |
| Серые звёзды | `MaterialTheme.colorScheme.outlineVariant` | нейтральный серый в обеих схемах, видимо темнее выбранных; новых токенов темы не нужно |

## Риски

- Теги-сироты после удаления последней привязки остаются в `tags` и попадают в
  подсказки. Это осознанно: тег может понадобиться снова, а чистка — отдельная
  задача; в подсказках он безвреден.
- Фильтрация по тегам загружает весь список библиотеки на каждый запрос. Для
  личной коллекции (тысячи строк) это те же данные, что уже читаются при пустом
  запросе; при росте — перейти на `name_search` + миграцию.
- `duration_*` меняет вид длительности во всех экранах, включая календарь —
  это желаемое единообразие.
